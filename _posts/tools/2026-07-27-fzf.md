## 들어가며

터미널을 오래 사용하다 보면 명령어를 입력하는 시간보다 예전에 사용한 명령어나 파일을 다시 찾는 시간이 더 아깝게 느껴질 때가 있다.

보안 진단 환경에서는 이런 일이 더 자주 생긴다. 이전에 사용한 긴 명령어를 조금만 수정해서 다시 실행하거나, 여러 디렉터리에 흩어진 스크립트와 워드리스트를 찾아야 하기 때문이다.

기본 명령어만으로도 찾을 수는 있다.

```powershell
Get-ChildItem -Recurse
Get-History
```

```bash
find . -type f
history | grep <검색어>
```

문제는 결과가 많아질수록 다시 `grep`이나 `Select-String`을 붙여야 하고, 파일 내용을 확인하려면 별도의 명령어를 실행해야 한다는 점이다.

이 과정을 줄이기 위해 `fzf`, `fd`, `bat`를 조합하고 다음 세 가지 함수를 만들었다.

```text
fh     명령 히스토리 검색
ff     현재 경로의 파일 검색 및 미리보기
ffh    숨김 파일을 포함한 검색 및 미리보기
```

이 글의 설정은 fzf 자체의 기본 단축키를 소개하는 내용이 아니라, PowerShell과 Kali WSL에서 비슷한 사용감을 얻기 위해 만든 개인 설정이다.

## 사용한 도구

세 도구가 담당하는 역할은 서로 다르다.

| 도구 | 역할 |
|---|---|
| `fzf` | 전달받은 목록을 대화형으로 검색하고 선택한다. |
| `fd` | 파일 목록을 빠르게 만들고 숨김 파일이나 제외 경로를 제어한다. |
| `bat` | 선택한 텍스트 파일을 줄 번호와 구문 강조를 적용해 보여준다. |

흐름을 단순하게 표현하면 다음과 같다.

```text
fd로 파일 목록 생성 → fzf로 검색 → bat으로 내용 미리보기
```

명령 히스토리는 `fd`가 필요하지 않다. 셸의 히스토리 파일을 읽어 `fzf`에 전달하면 된다.

## 완성된 명령어

설정을 마치면 PowerShell과 Kali에서 거의 같은 방식으로 사용할 수 있다.

```bash
fh
ff
ffh
```

검색할 경로를 직접 지정할 수도 있다.

```powershell
ff C:\Pentest
ffh C:\Users\USER\.config
```

```bash
ff /usr/share/wordlists
ffh ~/.config
```

`ff`와 `ffh`는 선택한 파일을 자동으로 실행하는 명령이 아니다. 파일 목록과 내용을 확인한 뒤 Enter를 누르면 선택한 경로를 터미널에 출력한다.

## Windows PowerShell 설정

### 도구 설치

`winget`으로 세 도구를 설치한다.

```powershell
winget install --id junegunn.fzf -e
winget install --id sharkdp.bat -e
winget install --id sharkdp.fd -e
```

설치 후 버전을 확인한다.

```powershell
fzf --version
bat --version
fd --version
```

새로 설치한 명령이 바로 인식되지 않으면 PowerShell을 다시 실행한다.

### PowerShell 프로필 열기

사용 중인 PowerShell에 따라 프로필 위치가 다르다.

```powershell
$PROFILE
```

일반적으로 Windows PowerShell 5.1은 다음 경로를 사용한다.

```text
C:\Users\USER\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1
```

PowerShell 7은 다음 경로를 사용한다.

```text
C:\Users\USER\Documents\PowerShell\Microsoft.PowerShell_profile.ps1
```

프로필이 없다면 파일을 만든 뒤 메모장으로 연다.

```powershell
if (-not (Test-Path -LiteralPath $PROFILE)) {
    New-Item -ItemType File -Path $PROFILE -Force | Out-Null
}

notepad $PROFILE
```

### 미리보기용 스크립트 만들기

Windows에서 fzf가 선택한 파일을 `bat`으로 보여주기 위한 보조 스크립트이다. `bat`이 없다면 기본 `type` 명령을 사용한다.

```powershell
$scriptDir = Join-Path $HOME 'Documents\PowerShell\Scripts'
$previewCmd = Join-Path $scriptDir 'ff-preview.cmd'

New-Item -ItemType Directory -Path $scriptDir -Force | Out-Null

$cmd = @(
    '@echo off',
    'where bat >nul 2>nul',
    'if %errorlevel%==0 (',
    '  bat --style=numbers --color=always -- "%~1"',
    ') else (',
    '  type "%~1"',
    ')'
)

Set-Content -LiteralPath $previewCmd -Value $cmd -Encoding ASCII
```

### `fh`, `ff`, `ffh` 함수 추가

아래 코드를 PowerShell 프로필 마지막에 추가한다.

```powershell
function fh {
    param([string]$Query = "")

    $historyPath = (Get-PSReadLineOption).HistorySavePath
    if (-not (Test-Path -LiteralPath $historyPath)) {
        return
    }

    $history = @(Get-Content -LiteralPath $historyPath)
    [Array]::Reverse($history)

    $target = $history |
        Where-Object { -not [string]::IsNullOrWhiteSpace($_) } |
        Select-Object -Unique |
        fzf --height 40% --layout=reverse --border --query="$Query"

    if ($target) {
        [Microsoft.PowerShell.PSConsoleReadLine]::DeleteLine()
        [Microsoft.PowerShell.PSConsoleReadLine]::Insert($target.Trim())
    }
}

function Invoke-FuzzyFilePreview {
    param(
        [string]$Path = ".",
        [switch]$Hidden
    )

    $fdArgs = @(
        '--type', 'f',
        '--color', 'never',
        '--path-separator', '/',
        '--exclude', '.git',
        '--exclude', 'node_modules',
        '--exclude', '.venv',
        '--exclude', '__pycache__',
        '--exclude', 'dist',
        '--exclude', 'build'
    )

    if ($Hidden) {
        $fdArgs += @(
            '--hidden',
            '--exclude', 'AppData',
            '--exclude', '.cache'
        )
    }

    $fdArgs += '.'
    $fdArgs += $Path

    $previewCmd = Join-Path $HOME 'Documents\PowerShell\Scripts\ff-preview.cmd'
    $previewCommand = '"' + $previewCmd + '" {}'

    fd @fdArgs |
        fzf --height 80% `
            --layout=reverse `
            --border `
            --preview $previewCommand `
            --preview-window=right:60%
}

function ff {
    param([string]$Path = ".")
    Invoke-FuzzyFilePreview -Path $Path
}

function ffh {
    param([string]$Path = ".")
    Invoke-FuzzyFilePreview -Path $Path -Hidden
}

Set-Alias fpreview ff
```

`C:\Users\USER`처럼 사용자명을 직접 적지 않고 `$HOME`을 이용하도록 구성하였다. 다른 PC에 프로필을 옮겨도 경로를 다시 수정할 부분이 줄어든다.

프로필을 다시 불러오면 바로 사용할 수 있다.

```powershell
. $PROFILE
```

정상적으로 등록되었는지 확인한다.

```powershell
Get-Command fh,ff,ffh,fpreview
Get-Command fzf,bat,fd
```

## Kali WSL 설정

### 도구 설치

Kali와 Debian 계열에서는 패키지 이름과 실제 실행 파일명이 다를 수 있다.

```bash
sudo apt update
sudo apt install -y fzf bat fd-find
```

`batcat`과 `fdfind`만 설치된 환경에서는 사용자 디렉터리에 심볼릭 링크를 만든다.

```bash
mkdir -p ~/.local/bin

command -v bat >/dev/null 2>&1 ||
  ln -sf /usr/bin/batcat ~/.local/bin/bat

command -v fd >/dev/null 2>&1 ||
  ln -sf /usr/bin/fdfind ~/.local/bin/fd
```

`~/.local/bin`이 PATH에 없다면 `~/.zshrc`에 다음 내용을 추가한다.

```zsh
export PATH="$HOME/.local/bin:$PATH"
```

설치 상태를 확인한다.

```bash
command -v fzf fd bat
fzf --version
fd --version
bat --version
```

### zsh 함수 추가

Kali의 기본 셸인 zsh를 기준으로 작성하였다. 아래 코드를 `~/.zshrc` 마지막에 추가한다.

```zsh
fh() {
  emulate -L zsh
  local selected

  selected=$(
    fc -lnr 1 |
      sed 's/^[[:space:]]*//' |
      fzf --height 40% --layout=reverse --border --query="$*"
  ) || return

  if [[ -n "$selected" ]]; then
    print -z -- "$selected"
  fi
}

_ff_run() {
  emulate -L zsh
  local include_hidden="$1"
  local base="${2:-.}"
  local -a fd_args

  fd_args=(
    --type f
    --color never
    --exclude .git
    --exclude node_modules
    --exclude .venv
    --exclude __pycache__
    --exclude dist
    --exclude build
  )

  if [[ "$include_hidden" == "1" ]]; then
    fd_args+=(
      --hidden
      --exclude .cache
    )
  fi

  fd "${fd_args[@]}" . "$base" |
    fzf \
      --height 80% \
      --layout=reverse \
      --border \
      --preview 'sh -c '"'"'
        if command -v bat >/dev/null 2>&1; then
          bat --style=numbers --color=always -- "$1"
        else
          cat -- "$1"
        fi
      '"'"' sh {}' \
      --preview-window=right:60%
}

ff() {
  _ff_run 0 "${1:-.}"
}

ffh() {
  _ff_run 1 "${1:-.}"
}

alias fp=ff
alias fpreview=ff
```

설정을 적용한다.

```bash
source ~/.zshrc
```

함수가 정상적으로 등록되었는지 확인한다.

```bash
zsh -n ~/.zshrc
zsh -ic 'whence -w fh; whence -w ff; whence -w ffh'
```

## 실제 사용

### 히스토리 검색

인자 없이 실행하면 전체 히스토리에서 검색할 수 있다.

```bash
fh
```

검색어를 함께 넘겨 처음부터 결과를 좁힐 수도 있다.

```bash
fh rustscan
fh install
```

선택한 명령은 바로 실행되지 않고 현재 입력줄에 들어간다. 내용을 확인하거나 일부 인자를 수정한 뒤 실행할 수 있어 긴 명령을 재사용할 때 편하다.

아래는 `install`이 포함된 명령을 히스토리에서 찾는 모습이다.

현재 디렉터리를 기준으로 파일을 찾는다.

```bash
ff
```

경로를 지정하면 해당 위치만 탐색한다.

```bash
ff /usr/share/wordlists
```

```powershell
ff C:\Pentest\02_Tools\Wordlists
```

Kali에서 워드리스트 경로를 검색하는 모습이다.

![Windows PowerShell에서 SecLists 파일을 검색하고 미리보는 화면](/images/2026-07-27-fzf/usage-screenshot-04.png)

파일이 많은 상위 디렉터리에서 무작정 실행할 수도 있지만, 평소에는 워드리스트나 도구가 있는 경로를 지정하는 편이 결과가 빠르고 깔끔하다.

### 숨김 파일 포함

기본 `ff`는 `fd`의 기본 동작을 따르므로 숨김 파일과 숨김 디렉터리를 제외한다.

```bash
ff
```

숨김 파일이 필요할 때만 `ffh`를 사용한다.

```bash
ffh
ffh ~/.config
```

여기서 `ffh`는 숨김 파일을 포함하지만 `.gitignore`, `.ignore` 등에 등록된 항목까지 모두 표시하는 명령은 아니다. 무시된 파일까지 전부 찾고 싶다면 `fd`에 `--no-ignore`를 추가하거나 `--unrestricted` 옵션을 사용하는 별도 함수를 만드는 편이 낫다.

## fzf 검색 문법

fzf 검색창에서는 몇 가지 문법을 조합할 수 있다.

```text
admin          퍼지 검색
'admin         admin을 정확히 포함
^admin         admin으로 시작
.txt$          .txt로 끝
!backup        backup이 포함된 결과 제외
```

여러 조건을 공백으로 이어서 입력할 수도 있다.

```text
^api .txt$ !backup
```

`fh`의 인자로 정확 일치 검색을 넘길 때는 셸의 따옴표 처리에 주의해야 한다.

`fh '/usr/share`처럼 앞쪽 작은따옴표만 적으면 fzf의 정확 검색을 의도한 것이어도 셸은 이를 문자열 따옴표의 시작으로 해석한다. fzf에 `'` 문자 자체를 전달하려면 다음과 같이 작성한다.

```bash
fh "'/usr/share"
```

이렇게 실행하면 `/usr/share`가 정확히 포함된 히스토리를 우선해서 찾을 수 있다.

## 사용하면서 정한 기준

### 검색 범위는 필요한 경로만 지정한다

홈 디렉터리나 루트부터 모든 파일을 찾으면 결과가 지나치게 많아지고 preview도 늦어진다.

```bash
ff /usr/share/wordlists
ff ~/tools
```

자주 사용하는 위치를 기준으로 실행하는 편이 실제 사용성이 좋았다.

### 숨김 파일은 필요할 때만 본다

숨김 경로에는 캐시와 프로그램 설정 파일이 많이 들어 있다. 평소에는 `ff`를 사용하고 설정 파일을 찾을 때만 `ffh`를 사용하도록 분리하였다.

### preview는 텍스트 파일에 집중한다

이미지, PDF, 압축 파일까지 파일 형식별로 미리보게 만들 수도 있다. 다만 preview 명령이 복잡해지고 큰 파일을 선택했을 때 반응이 느려진다.

이 설정에서는 스크립트, 설정 파일, 워드리스트처럼 자주 확인하는 텍스트 파일을 빠르게 보는 쪽을 선택하였다.

## 문제가 생길 때 확인할 부분

### `fd` 또는 `bat` 명령을 찾지 못하는 경우

Kali에서는 실제 실행 파일이 `fdfind`, `batcat`인지 먼저 확인한다.

```bash
command -v fdfind
command -v batcat
echo "$PATH"
```

### PowerShell에서 함수를 찾지 못하는 경우

현재 셸에서 사용하는 프로필과 수정한 파일이 같은지 확인한다.

```powershell
$PROFILE
Test-Path -LiteralPath $PROFILE
. $PROFILE
```

프로필을 다시 불러올 때 오류가 나오면 표시된 줄부터 확인한다.

### 예상한 파일이 나오지 않는 경우

`fd`는 기본적으로 숨김 항목과 ignore 파일에 등록된 경로를 제외한다.

```bash
fd --hidden <검색어>
fd --no-ignore <검색어>
fd --unrestricted <검색어>
```

목적에 맞는 옵션을 선택하면 된다. 단순히 숨김 설정 파일만 찾는 경우에는 `--hidden`, 정말 모든 경로를 확인해야 하는 경우에는 `--unrestricted`가 적합하다.

## 마무리

`fzf` 하나만 설치해도 히스토리 검색은 충분히 편해진다. 여기에 `fd`로 파일 목록을 만들고 `bat` preview를 붙이면 스크립트나 워드리스트를 찾는 과정도 한 화면에서 끝낼 수 있다.

처음에는 alias 몇 개를 추가하는 정도로 시작했지만, 실제로 사용해 보니 `fh`, `ff`, `ffh`처럼 목적을 분리한 구성이 가장 단순했다. Windows와 Kali에서 명령 이름을 같게 맞춘 것도 환경을 오갈 때 생각보다 편했다.

복잡한 파일 관리 도구를 만드는 것이 목적은 아니다. 이전 명령을 다시 찾고, 필요한 파일의 내용을 잠깐 확인하는 데 드는 동작을 줄이는 것이 이 설정의 핵심이다.
